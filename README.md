# Hindsight 记忆工作台

为 DeepSeek Harness 提供跨会话长期记忆、任务复盘和 Skill 草稿的简体中文工作台。把明确的项目约定和偏好留给下次使用，让反复验证过的做法有据可查。

[插件市场条目](https://awesome-dsh-plugin.com/p/xiaochouxia11/dsh-hindsight-workbench/) · [正式版下载](https://github.com/xiaochouxia11/dsh-hindsight-workbench/releases/latest) · [安装与换机指南](docs/INSTALL.zh-CN.md)

## 公开下载与兼容性

本项目按 MIT 许可公开。游客可以查看源码和文档、下载正式版安装包。安装插件需要可用的 DeepSeek Harness 和下载依赖的网络连接，无需仓库访问授权。

当前插件声明的 Harness 兼容范围是 `>=0.2.1-rc.5 <0.3.0-0`，跨平台实际验收使用官方 CLI `0.2.2-rc.5`。已验证 Windows x64、macOS ARM64 和 Linux x64 的空白配置安装、单采集器挂载、后端离线时保存中文笔记及重启恢复。

## 第一次使用

1. 打开 DeepSeek Harness 的「插件市场」，搜索 `dsh-hindsight-workbench` 并安装。重开 Harness 后打开左侧「Hindsight 记忆工作台」。
2. 在项目会话中试一句「以后验收格式：清单」。回合结束后，到「进化」选中该项目库，查看新记录。换一个同项目会话谈到验收格式时，可以按相关性取回这条约定。
3. 到「长期记忆」手动保存一条偏好或经验。若要使用语义召回和 AI 知识库，到「检查」确认本机 Hindsight 后端已连接。

更多逐步操作及预期结果见 [使用手册](docs/INSTALL.zh-CN.md#3-从安装到实际使用)，包括跨会话记忆试用、复盘、知识导入和 Skill 草稿。

## 数据与依赖

| 功能 | 使用条件 |
| --- | --- |
| 本机长期笔记、选择性学习和进化日志 | 兼容版本的 Harness。自动采集需要有效的项目工作目录 |
| Hindsight 记忆浏览、语义召回、AI 知识库 | 本机 Hindsight 后端。AI 知识库需可用的文档索引和检索接口 |
| 把 Skill 草稿正式安装 | 已启用 `@michengai/dsh-skills-manager`，由用户确认保存 |

项目与全局记忆分开。自动规则可归档和恢复，默认使用本机选择性写入。换机安装和迁移旧记忆是两个步骤，迁移时参照安装指南。Windows x64、macOS ARM64 和 Linux x64 已通过 [官方 Harness CLI 跨平台验收](https://github.com/xiaochouxia11/dsh-hindsight-workbench/actions/workflows/clean-harness.yml)。

## 功能

- **记忆库切换**：自动列出本机 Hindsight 中的记忆库（同一 `coding-agent::` 命名空间），下拉切换项目库后立即重读数据，选择会记住。全局库由「全局库」范围进入。
- **总览**：连接状态、事实数、关联数、文档数、待处理操作。
- **记忆列表**：项目库 / 全局库 / 联合搜索三种范围。关键词搜索原文与上下文，也可按含义召回，用来源标记打开实际记录。联合查询按来源分组。
- **长期记忆**：手动保存偏好、项目事实与经验，支持编辑、搜索、归档和恢复。本机笔记按所选项目库或全局库保存，之后打开其他会话也可查找。
- **会话项目隔离**：随包采集器默认使用真实的项目路径生成库 ID，同名项目使用不同库。可以显式映射到已有库。
- **记忆详情**：原文、时间、类型、实体、标签、元数据、已有关系图。观察可按需查看旧版本，其他有来源文档的记忆可查看写入、修正和整理历史。
- **知识库**：知识页树与正文阅读，支持页内选择与关键词命中。
- **AI 知识库**：Hindsight 1.3.0 提供原生知识库接口。可新建工作台知识库、导入文本或 Markdown、检索并查看原文。导入和检索需要 Hindsight 配置的嵌入运行环境。
- **技能**：列出 `DSH_HOME/skills` 下的技能。安装并启用 `@michengai/dsh-skills-manager` 后，可用名称、简介和 Markdown 正文添加 DSH Skill。已有同名技能由技能管理器拒绝覆盖。
- **安装检查**：本机服务健康、项目/全局记忆库状态、上游采集器挂载情况与安装步骤；服务未启动时给出启动提示。
- **选择性记忆**：识别明确的长期偏好和纠正，排除本次指令、单文件要求、假设问题和明显的凭据。默认写入项目库，只有明确声明全局范围才写入全局库。同主题纠正可用「以后格式：表格」和「不对，以后格式：清单」这一类带主题的表达。普通指令在三个独立会话出现后进入长期记忆。可在「进化」页查看证据、归档和恢复。
- **复盘与进化**：多步骤回合结束后，根据 Harness 实际记录的检查、修改、构建和验证结果生成简短复盘。相同流程在三个独立会话验证通过后，可打开预填的 Skill 草稿。补全具体操作并确认后才创建 Skill，草稿仍可在本机保存和恢复。已有 Hindsight 记忆也可手动提炼为草稿。

## 安装

安装在 DSH 应用内完成，插件自带上游采集集成依赖 `@vectorize-io/hindsight-coding-agents@0.8.8`，**不需要另外安装采集器**：

1. 打开 DSH 的插件管理 / 插件市场，在已配置市场中搜索 `Hindsight 记忆工作台` 或 `dsh-hindsight-workbench`。是否出现取决于市场收录和刷新进度。
2. 也可从 [GitHub Releases](https://github.com/xiaochouxia11/dsh-hindsight-workbench/releases) 获取插件包，在 DSH 插件管理器中安装。
3. 安装后刷新页面或重开 DSH，左侧栏出现「Hindsight 记忆工作台」，也可以按 `Alt+Shift+H` 打开。

浏览 Hindsight 记忆、按含义召回和管理 AI 知识库需本机 Hindsight 后端（默认 `http://127.0.0.1:9077`）。按 [简体中文安装向导](docs/INSTALL.zh-CN.md) 检查依赖及服务状态。本机长期笔记独立于后端运行。

## 配置

宿主配置字段（由 DSH 官方配置能力提供，界面没有保存连接的表单）：

```json
{"endpoint":"http://127.0.0.1:9077","bank":"project-bank-id","globalBank":"global-bank-id"}
```

- `endpoint` 仅接受无凭证的本机回环 HTTP origin（`127.0.0.1` 或 `[::1]`，端口可改）。
- `bank` 与 `globalBank` 必须不同。默认使用 `coding-agent::default` / `coding-agent::global`。页面恢复仍可用的上次项目选择，其次使用配置的项目库，再由用户从清单选择。
- 项目下拉项限于配置库及同一命名空间（`::` 前缀相同）的库，配置的全局库从下拉项排除。全局范围始终读取宿主配置指定的全局库。

## 数据与部署

- 宿主提供固定的健康、记忆、知识库、召回、长期笔记和草稿接口。记忆详情、历史、关系均为只读。按含义召回使用 Hindsight 的检索和排序配置。
- 前端渲染纯文本，不执行 HTML、不加载外部资源。
- 严格 UTF-8 解码，解码失败与疑似异常文本分别提示；请求 12 秒超时、响应上限 16 MB。
- 官方上游清单只返回白名单状态字段，不读取凭证。
- 已挂载的采集器使用会话所在项目自动学习，按相关性最多召回五条、合计不超过 1,000 个字符的本机规则。同主题的项目规则在本项目优先。现有 Hindsight 后端记忆仍可浏览和检索。选择工作台库只会切换界面。自动筛选和复盘采用本机规则，支持常用中文表达和常用开发工具，无需另一次模型调用。可识别的表达和命令有限。
- 新增自动记忆和复盘写在 Harness 数据目录的 `storages/dsh-hindsight-workbench/learning`。默认停止将完整对话交给 Hindsight 后端提取。需要原有完整会话采集时，可显式设置 `DSH_HINDSIGHT_RETAIN_TRANSCRIPTS=1` 后重启 Harness；已有记忆库不会被清空。

## 使用场景与常见问题

| 想做什么 | 在哪里操作 |
| --- | --- |
| 让同一项目以后的验收统一用清单 | 在有有效工作目录的项目会话中说「以后验收格式：清单」。回合结束后到「进化」查看。换一个同项目的会话，再提到验收格式 |
| 纠正已经保存的规则 | 沿用同一主题，例如「不对，以后验收格式：表格」。到「进化」核对新规则和旧记录 |
| 保存一条适用于所有项目的偏好 | 明确说明范围，例如「所有项目都用简体中文」。切换到「全局库」确认记录 |
| 看流程为什么能提炼成 Skill | 在「进化」查看流程的来源与验证次数。达到三次独立验证后可打开草稿、补全命令和步骤，再确认安装 |
| 忘掉一条自动规则 | 在「进化」归档它。已归档规则停止自动召回，可通过「查看归档」恢复 |
| 导入自己的资料 | 到「AI 知识库」创建知识库并导入 UTF-8 文本或 Markdown。等索引完成后再检索和查看原文 |

**自动记忆没出现？** 先确认会话有有效工作目录，然后到「检查」确认只挂载了一个采集器。自动识别覆盖常用中文句式。临时指令、单文件要求与假设性问题通常会被过滤，普通重复指令需要三个独立会话。表达较复杂时，可在「长期记忆」手动保存。

**服务未连接？** 本机学习日志和长期笔记仍可用。Hindsight 语义召回与 AI 知识库须在目标电脑启动并配置本机后端。知识库页和 Hindsight 的已有知识页是不同入口。创建 Skill 还需要启用技能管理器。

**换电脑后找不到旧记录？** 安装包只含程序。旧笔记、学习日志和草稿需要私下备份迁移。Hindsight 后端数据需单独备份恢复。项目路径不同的情况下，可按指南把新路径映射到旧项目库。本版没有跨设备自动同步功能。

**卸载或回退？** 在 Harness 插件管理器中卸载，或用已验证的旧版安装包回退。插件、本机记忆和后端数据各自管理，准备迁移或回退时先备份自己的记忆。详细步骤见 [安装与换机指南](docs/INSTALL.zh-CN.md)。

## 构建与测试

需要 Node.js 20+。先使用 `npm install --ignore-scripts` 安装已固定版本的构建依赖。

```sh
npm run build   # 复制 src → dist
npm test        # 回归测试
npm run check:public-pack   # 公开包内容预检（需 npm）
```

宿主入口 `dist/index.js`，客户端入口 `dist/client.js`。
